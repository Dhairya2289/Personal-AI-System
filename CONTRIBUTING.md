# Contributing to Hermes Mission Control AI OS

Thank you for considering contributing! We welcome bug fixes, documentation improvements, and new feature enhancements.

## Development Workflow
1. **Fork the Repository**: Create your feature branch (`git checkout -b feature/amazing-feature`).
2. **Setup Local Venv**: Follow the setup steps in [README.md](README.md).
3. **Verify Code Quality**: Ensure `python -m py_compile *.py` returns 0 errors.
4. **Commit Changes**: Use clean commit messages following Conventional Commits format (`feat: ...`, `fix: ...`, `docs: ...`).
5. **Open Pull Request**: Submit a PR to `main` for review.

## Code of Conduct
Please adhere to our [Code of Conduct](CODE_OF_CONDUCT.md) in all interactions.
