# Security Policy

## Supported Versions
The current `main` branch is actively supported with security updates.

## Reporting a Vulnerability
If you discover a security vulnerability in Hermes Mission Control AI OS, please do **NOT** open a public issue. Instead, report it privately to the maintainer via email:

* **Contact Email**: `dhairya9247@gmail.com`

We will acknowledge receipt of your report within 48 hours and work with you to release a security patch.
